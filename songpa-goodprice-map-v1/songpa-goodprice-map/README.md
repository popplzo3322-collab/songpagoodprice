# 송파구 착한가격업소 지도 V1.0
첨부 서울시 CSV에서 송파구 92개 업소, 206개 품목을 추출했습니다. 원본에는 좌표와 기준일 컬럼이 없습니다. 실제 좌표는 카카오 주소 검색 SDK로 조회하며 실패한 주소는 목록에 남습니다. 주소 결과는 건물 기준이며 출입구 실측 위치가 아닙니다.
## 실행
1. pip install -r requirements.txt
2. .streamlit/secrets.example.toml을 .streamlit/secrets.toml로 복사하고 카카오 JavaScript 키를 입력합니다. Streamlit Cloud에서는 Secrets 설정에 같은 내용을 입력합니다.
3. 카카오 개발자 콘솔에 실제 서비스 도메인을 등록하고 지도 API 사용 설정을 확인합니다.
4. streamlit run app.py
## 기능
업종·품목·가격 상한·검색어 동시 필터, 가격순 정렬, 지도 마커, 길찾기, 현재 위치(브라우저 허용 시). 위치 조회 실패 시 지도에서 제외하되 검색 목록은 유지합니다. 데이터 갱신 자동화 및 영구 좌표 보정은 미구현입니다. 외부 공개 전 실제 배포 환경에서 카카오 SDK, iframe 위치 권한, 웹 접근성, 보안 및 주소 결과를 검증해야 합니다. 공식 서비스 승인을 받은 뒤 CI를 적용하세요. API 키를 커밋하지 마세요.
